# 🚀 Missão Rover Lunar

Projeto desenvolvido para a disciplina de **Garantia da Qualidade de Software / Gestão e Qualidade de Software**.

O objetivo é praticar o uso do GitHub, branches, commits, Pull Requests e integração entre as branches `develop` e `main`.

- Fernando Almeida de Oliveira Braga

## 🛰️ Sobre o Projeto

O projeto consiste em um programa desenvolvido em Python para simular a inicialização dos sistemas de um Rover Lunar.

Durante a inicialização são verificados os seguintes sistemas:

- Sistema de energia
- Sistema de comunicação
- Sistema de navegação
- Sensores
- Controle de movimento

Após a inicialização dos sistemas, o programa informa que o Rover está pronto para a missão.
